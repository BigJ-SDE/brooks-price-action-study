# TTR (Tight Trading Range)

## 简单定义

- （source-explicit，Video08C Slide 2）小型紧密震荡区间。若 context 不好，更可能持续；持续 10-20 根 bar 后，尤其非常紧密时，最好等待突破。

## Brooks 明确表达

- （source-explicit，Video08C Slide 2, 01:05）Small TTR: Needs Good Context for Breakout (BO)。
- （source-explicit，Video08C Slide 9, 10:10）Small TTR: Can Be Trend Resumption Setup (Flag)——即使是小型形态，如果 context 好，也能获得突破；好 context 指的是有理由预期趋势中出现支撑或阻力处的波段回调。
- （source-explicit，Video08C Slide 18, 23:06）TTR: Higher Probability If Final Bar Is in Correct Direction——最终旗形买入 setup 的最后一根 bar 方向与预期一致时，概率更高。

## 我的理解

- （student-interpretation）TTR 本身是中性的，能否成为高概率的旗形（Flag）延续，取决于左侧 context 是否支持。

## 有利环境

- 处于明确趋势中、有理由预期在支撑/阻力附近出现波段回调时。

## 不利环境

- 趋势晚期的大突破之后出现的 TTR，更可能预示力竭反转而非延续。
