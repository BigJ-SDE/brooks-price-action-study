# Value Traders / Value Investors

## 简单定义

- （source-explicit，Video02B/02C）只在价格便宜时买入、价格昂贵时卖出的交易者；在阻力处卖出、支撑处买入。

## Brooks 明确表达

- （source-explicit，Video02B）Value Traders: Buy When Cheap——价值型机构只在市场极度便宜时买入；没有人真正知道"正确价格"是多少，但价值投资者对何时"便宜"有较好的判断；强劲的看涨动能出现时，交易者会仅因为价格在上涨而买入，原因并不重要。
- （source-explicit，Video02C）在阻力处卖出、支撑处买入的交易者是"Value Investors"，他们希望在市场便宜时买入、昂贵时卖出。

## 我的理解

- （student-interpretation）Value Traders 的行为与支撑/阻力位的有效性直接相关——他们是在支撑/阻力处产生买卖压力的主要力量之一。

## 有利环境

- 明确的支撑/阻力位附近。

## 不利环境

- 不适用。
