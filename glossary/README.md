# glossary/

保存正式确认的术语与概念定义，每个概念一个 Markdown 文件。

- 使用 [../templates/concept-template.md](../templates/concept-template.md) 创建新文件。
- 文件仅在**用户确认**后创建或更新，之前只在 `lessons/` 或复习草稿中作为候选提出。
- 概念 ID 格式：`PA-CONCEPT-0001`，创建前先检查 [../indexes/concepts.md](../indexes/concepts.md) 避免重复。
- 创建/更新后需同步更新 [../indexes/concepts.md](../indexes/concepts.md)。
